gebraucht werden. Bewusst **aufbewahrt statt gelöscht**: Sie dokumentieren,
*wie* ein Zustand entstanden ist — das ist bei einer späteren Fehlersuche
wertvoller als ein aufgeräumtes Verzeichnis.
